## 🌐 Live Website

- **Live Demo:** 
https://novatech-learning.vercel.app/

## 📖 About the Project

NovaTech Learning is a responsive tutor portfolio designed to present technology education services in a modern, professional, and student-friendly way.

The website helps learners explore available subjects, discover practical learning opportunities, review project work, and contact the tutor for further information.

## 🎯 Learning Subjects

- **Programming Fundamentals** — Programming concepts, problem-solving, and coding practice.
- **Web Development** — HTML, CSS, JavaScript, Bootstrap, PHP, and Laravel.
- **Database Management** — Database design, SQL, MySQL, and CRUD operations.
- **Software Engineering** — Software development life cycle, requirements, design, and testing fundamentals.
- **IT Fundamentals** — Computer systems, networking basics, and essential IT concepts.
- **Data Science Fundamentals** — Introduction to data analysis and data science concepts.

## 🚀 Run the Project Locally

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd novatech-learning
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

4. To test the contact form, configure the required server-side API and environment variables before submitting enquiries.

## ☁️ Deployment on Vercel

The website can be deployed using Vercel and connected to a GitHub repository.

1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Configure the project settings and any required environment variables.
4. Deploy the project.
5. Test the live website, responsive layout, and contact form.

### Contact Form Security

The Resend API key must be stored as a server-side environment variable in Vercel. Never expose the API key in browser-side JavaScript or commit it to GitHub. The contact form must send requests to a server-side API endpoint that handles email delivery securely.
